# IVAN Android port notice

This repository is an unofficial Android port of Iter Vehemens ad Necem
(IVAN), based on Attnam IVAN commit `de528ac06d24674675c7ca828d84d72003850f27`.
It is not an official Attnam release and is not endorsed by the original IVAN
authors or the Attnam maintainers.

Android-port modifications were made during August 2026 by the `harminoff`
fork contributors. They include the SDL Android host and storage integration,
touch controls, responsive portrait and landscape presentation, mobile menus
and prompts, extracted stats and message presentation, Android audio support,
and supporting portability changes.

IVAN is offered under GNU GPL version 2 or, at your option, any later version.
Because this Android build incorporates xBRZ code offered under GNU GPL
version 3 or later, the combined Android work is conveyed under GNU GPL
version 3 or later. The complete GPLv3 text is stored at
`xbrzscale/License.txt` and packaged in Android builds as
`licenses/GPL-3.0-or-later.txt`. The original IVAN GPLv2 text and notices are
retained in `COPYING` and `LICENSING`.

Corresponding source, including Android build scripts and vendored native
dependencies, is published at:

https://github.com/harminoff/ivan

Release tags identify the exact source corresponding to published APKs.
Third-party component notices are described in `THIRD_PARTY_NOTICES.md`.
