IVAN 0.59 - Readability and Stability Update (Windows)

Extract the complete ZIP before launching ivan.exe inside the ivan folder.
All required game assets and runtime DLLs are included.

This update includes readable description paragraphs, clearer god information,
safer equipment changes, and Origins character starts in the enhanced UI.
Keyboard and mouse controls and the classic interface remain available.

To keep an existing adventure, copy the Save folder from your previous IVAN
installation into the new ivan folder. Keep the original installation as a
backup. Existing local settings can be copied separately if desired.
